Algorithm Details

1. K-Medoids Clustering

Groups sensor nodes into k zones using Haversine distance. Unlike K-means, medoids are actual node positions — physically meaningful cluster centres.

2. Weiszfeld's Algorithm

Finds the geometric median (L1 centre) of each zone's node positions. This minimises total pipe length to all sensors — optimal valve placement.
